MPXJ Reader

UniversalProjectReader detects and reads supported schedule formats, including Microsoft Project MPP and Primavera XER.

XER Output

Primavera P6 XER is generated using MPXJ's XER writer from the in-memory ProjectFile model.

Microsoft Project XML

MSPDI is Microsoft's XML interchange format and can be opened by Microsoft Project.

Browser Filesystem

Your selected schedule is mounted in CheerpJ's transient filesystem so Java/MPXJ can read it as a normal file.

Direct Download

The converted output is read back from the browser-side Java filesystem and downloaded without a backend request.
